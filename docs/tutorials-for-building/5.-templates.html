5. Templates

Templates let you reuse tables and whole projects instead of building them again. There are two kinds:

  • Table templates (also called row templates): one or more tables, with their columns, references and indexes.
  • Project templates: a whole project, including RLS, the API design and every NodeWalker graph.

Templates belong to your account, not to one project, so a template you make is offered in every project.

Using a table template

  1. Open Table Editor and press +.
  2. Press Use A Template.
  3. Find the pack you want and press Select Template Pack.

The pack's tables are added to the open project. A table that already exists in the project (same schema and name) is left alone, and you're told which ones were skipped. Afterwards you can edit the new tables like any other.

Using a project template

  1. Open Projects and press Create New Project.
  2. Press Edit Template and pick a project template. You can also pick table templates here to add on top.
  3. Give the project a name and description and press Enter.

Making a table template

Open Build Project and press Export Specific Rows. The form has four tabs:

  1. Templates: pick the tables to include. Each one you pick shows up on the right, where you can give it a description.
  2. Pack Information: a banner (optional, 1500x200), the template name and an overview.
  3. Author: your name, plus an optional picture, company, website, license and note.
  4. Finalize: check the preview and press Finalize.

The list on the Finalize tab says what's still missing and updates as you type. A name can't contain any of \ / : * ? " < > |, because it becomes a folder name.

The template is saved to:

DatabaseDesignerData\<your username>\Row Templates\<Template Name>\v1\

Building a template with the same name again makes v2, v3 and so on. The newest version is the one offered when you use it.

Making a project template

  1. Open Build Project and press Export Template.
  2. Pick the project.
  3. Fill in the same information as above and press Finalize.

It's saved to DatabaseDesignerData\<your username>\Project Templates\<Template Name>\, together with the project's session.json, its Scripts folder (your NodeWalker graphs), its icon and its wallpaper.

Templates that come with the app

These are installed the first time you log in. Installing never overwrites a template you've changed.

Kind Template Tables
Table User Accounts users
Table Blog Posts posts
Table Inventory Items items
Project Secure Sign-In users, sessions
Project Simple Chat users, messages
Project Simple Marketplace users, items, orders
Project Simple Store users, products, orders, plus five API functions with their graphs

Simple Store is the finished version of 9. Guide - Building A Simple Store.

Sharing templates

Templates are saved unencrypted, so you can open them, check what's inside and send them to someone else. To install one, copy its folder into your own Row Templates or Project Templates folder.

Templates made with versions before 3.0 may not load. If one gives you trouble, delete its folder and export it again.
