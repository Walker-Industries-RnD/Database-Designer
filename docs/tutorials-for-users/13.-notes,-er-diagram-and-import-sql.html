13. Notes, ER Diagram And Import SQL

Three desktop apps that help while you design: Notes for keeping track of things, ER Diagram for seeing the whole database at once, and Import SQL for bringing in a database you already have.

All three need a project to be open.

Notes

Notes keeps notes inside your project, so your to-do list and design ideas stay with the tables they're about.

  • + New makes a note. Type its title in the box at the top and the note itself underneath.
  • Notes save by themselves as you type.
  • Pin keeps a note at the top of the list.
  • Type in Search notes... to find a note by its title or text.
  • Pick a table in the Table box to link the note to that table.
  • Lines that start with [ ] or [x] become checklist items.
[x] Add products table
[ ] Add RLS for orders
[ ] Try checkout on Local Database

Notes are encrypted with the rest of the project, and they're included when you export it. The text box fills the window and scrolls, so long notes are fine.

ER Diagram

ER Diagram draws every table as a card with its columns, and an arrow for every reference. Columns are marked PK (primary key), FK (foreign key) and UQ (unique).

  • Drag a card by its title to move it. Your layout is saved with the project.
  • Auto layout puts everything back in neat rows.
  • The - and + buttons zoom out and in, and 100% resets the zoom.
  • Click a card's title to open that table.
  • Export SVG and Export PNG save a picture of the diagram to Exports\ER Diagrams and open the folder. SVG stays sharp at any size; PNG is easier to paste into chats and documents.

It's the quickest way to spot a reference pointing at the wrong table, or a table that isn't connected to anything.

Import SQL

Already have a Postgres database? Import SQL turns its schema into tables in your project.

  1. Paste the SQL into the box on the left, or press Load .sql file.... A pg_dump --schema-only file works.
  2. Check the preview on the right. It lists every table it found, and anything it skipped.
  3. Set the Default schema for tables that don't name one (usually public).
  4. Tick Replace tables that already exist if you want imported tables to overwrite ones with the same name. Otherwise they're skipped.
  5. Press Add to project.

It reads tables, columns, defaults, primary keys, foreign keys, unique and check constraints, indexes and comments. Functions, triggers, grants and data are skipped and listed, so you can see what was left out.

Afterwards, run Build Project > Build Check to see if anything needs fixing, like reserved words or column names with capital letters.

💜 Moving in? Bring your stuff!

Got a database from some other project? Don't you dare rebuild it table by table. Dump the schema, import it, and you're done in a minute. Then go fix whatever Build Check yells at you about.
