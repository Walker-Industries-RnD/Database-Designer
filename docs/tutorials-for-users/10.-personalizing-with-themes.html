10. Personalizing With Themes

1. What themes do

Themes recolor the login screen, the desktop, projects, tables, the designer and more. Under the hood every surface reads from a small shared palette, so switching a theme repaints all of it at once. A theme can also set a background wallpaper.

Database Designer ships on the plain Default look. It also comes with a few built-in themes you can switch to whenever you like — including a Y2K Chrome look with a frutiger-aqua wallpaper.

Note: This system is experimental and Is Reccomended For Usage In The Next Update

💜 Default is the default — themes are opt-in!

Out of the box you get the plain Default palette. Nothing changes until you pick a theme. Fancy something different? Apply one of the built-ins, or make your own in about a minute. And you can always flip back to Default. Keep reading, dummy. 🐰


2. Switching themes

  1. From the main desktop, open the Themes app.

The Themes window lists every theme you have.

  1. For each theme you get two buttons:
    • Apply — switches to that theme right now, just for this session.
    • Set Default — applies it and remembers it, so it loads automatically every time you launch Database Designer.

The theme currently set as your default is marked with a DEFAULT pill.

3. The built-in themes

Theme Look
Y2K Chrome Electric indigo ink + icy chrome, with a bright frutiger-aqua wallpaper
Midnight Near-black background with soft off-white text
Sandstone Warm dark stone with cream text
Default The app's plain baseline palette, no wallpaper (this is what you start on)

4. Making your own theme

A theme is just a folder with a theme.json file inside it.

  1. Open your user folder and go into the Themes folder (this is where the built-in themes live too).
  2. Make a new folder named whatever you want your theme to be called — e.g. My Theme.
  3. Inside it, create a theme.json like this:
{
  "Colors": {
    "Theme_BackgroundColor": "#1D1A6B",
    "Theme_TextOnPrimaryColor": "#E6F4FF",
    "Theme_TextBrush": "#161257"
  },
  "BackgroundImage": "background.jpg"
}

What the keys mean:

Key Controls
Theme_BackgroundColor The main "ink" color — most text and primary surfaces
Theme_TextOnPrimaryColor The light/contrast color — panels and text sitting on the ink
Theme_TextBrush The default body-text color
  • Colors are hex, #RRGGBB (or #AARRGGBB if you want transparency).
  • BackgroundImage is optional — drop an image (e.g. a .jpg or .png) next to theme.json and name it here. Leave it out for a color-only theme.
  1. Back in the Themes app, your theme now appears in the list. Hit Apply to try it, or Set Default to keep it.

💜 Tip: start from a copy!

The easiest way to build your own is to copy the Y2K Chrome folder, rename the copy, and tweak the three colors until it looks right. You literally cannot break anything — a bad color just falls back to a safe default. Go wild! 🌟
